
# Sistema de Aluguel de Livros

## Descrição
O projeto consiste no desenvolvimento de um sistema para gerenciar o aluguel de livros em uma biblioteca, facilitando o controle do acervo, dos usuários e dos empréstimos realizados.

## Objetivo
Desenvolver uma aplicação web utilizando Python e FastAPI para organizar o processo de empréstimo e devolução de livros.

## Funcionalidades previstas
- Cadastro de livros;
- Cadastro de usuários;
- Consulta aos livros disponíveis;
- Registro de empréstimos;
- Registro de devoluções;
- Consulta aos empréstimos realizados.

## Tecnologias utilizadas
- Python
- FastAPI
- Pytest
